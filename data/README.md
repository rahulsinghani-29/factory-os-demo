# Synthetic data only

The PO/plan/handoff records, hourly production data, source notes and images are invented. Camera-style images are AI-generated examples, not real factory photographs. They can contain text-generation errors.

The live image path reads the actual photo. It does not pass fixture rows or expected outcome labels to OCR or inference. Context defaults are editable records, not production API responses.

Only the generated `*-camera-v2.png` examples and their invented S10 context are included. No uploaded personal image, original floor note or recorded run is included.
